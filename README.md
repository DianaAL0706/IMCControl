# IMC Control – Sistema de Seguimiento del Índice de Masa Corporal

## Descripción del proyecto

IMC Control es una aplicación web desarrollada en Java cuyo propósito es facilitar el cálculo y seguimiento del Índice de Masa Corporal (IMC) de los usuarios.

El sistema permitirá registrar información personal, iniciar sesión, calcular el IMC a partir del peso y la estatura, y consultar un historial de mediciones almacenadas en una base de datos.

## Objetivo

Desarrollar una aplicación web que permita a los usuarios calcular y consultar su Índice de Masa Corporal, manteniendo un registro histórico de sus mediciones mediante una interfaz sencilla y organizada.

## Funcionalidades principales

- Registro de usuarios con validación de datos personales.
- Inicio de sesión mediante nombre de usuario y contraseña.
- Cálculo automático del Índice de Masa Corporal.
- Almacenamiento de mediciones en una base de datos.
- Consulta del historial de IMC mediante un servicio web REST.
- Visualización de resultados y mediciones anteriores.

## Tecnologías utilizadas

- Java 8
- Jakarta EE 8
- Apache NetBeans IDE 17
- Apache Maven
- GlassFish Server 5.1
- JSP y Servlets
- Arquitectura Modelo-Vista-Controlador (MVC)
- Servicios web REST
- Git y GitHub

## Arquitectura del sistema

La aplicación seguirá el patrón Modelo-Vista-Controlador (MVC), separando la lógica de negocio, las interfaces de usuario y el control de las solicitudes HTTP.

Se contempla el uso de clases para administrar usuarios, calcular el IMC, gestionar los registros y recuperar el historial mediante un servicio REST.

## Estado del proyecto

En desarrollo. Actualmente se cuenta con el diseño de las interfaces, el diagrama de clases UML y el modelo de base de datos.
